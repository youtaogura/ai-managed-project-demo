# Issue #122 見た目を直す: 読み終えた・書き出しの続きを書く

## 背景・目的

#107 の続き。`FinishedScreen`（読み終えた）と `WriteScreen`（書き出しの続きを書く）を、`docs/design-system/screens/finished.png` / `write.png` と見比べて直す。`cd app && pnpm shots -- finished write` で今の画面を撮り（`app/.screenshots/`）、画像と見比べる。画像と部品 README が食い違うときは部品 README を優先する。色・余白・角丸・文字は `design/tokens.ts` のトークンで直し、画像から数値を読まない。画像の本・作者・文章はサンプルなので中身の違いは直さない。依存の #107 / #117（`Spine`/`Shelf` 直し済み）は main に入っている。

## スコープ

### やること

実装担当は撮影して「確認する項目」を1つずつ見比べる。以下は仕様担当が画像・README・現行コードから推測した「差の候補」。撮って確かめ、違わなければ「一致」とする。ここに無い差も見つけたら直す。

**読み終えた（`FinishedScreen`）**

| 項目 | 差の候補 | 直す方向 |
|---|---|---|
| 背表紙と棚板、「読み終えた」（朱）、タイトル、「M/D – M/D · N 日間 · メモ N 件」 | `Shelf` 幅 96 の固定値（`SPINE_SHELF_WIDTH`）、各行の余白（`gap: space[3]`） | 画像と比べ、`space` から選ぶ。サマリー文言は `buildFinishedSummary` のまま |
| 「どうだった？」の星の大きさ・間隔、数字と言葉、言葉の目安 | **現行は `RatingSlider`。RatingStars README は入力の星を 34px と定める**。星サイズ・間隔、数字（`displayNumber`）と言葉（朱の明朝）の並び、目安 `RATING_GUIDE` の文字 | `RatingSlider` の星サイズ・間隔を README に合わせる。評価未入力のときの表示も確認 |
| 「お気に入りにする」のトグル | カード（`surface1`＋枠線）の高さ・文字の太さ、`Toggle` の大きさ・色 | `Toggle` README と比べる。`Toggle` を直す場合は使う他画面（設定等）も撮って確認 |
| 下に固定の「記録を書く」「あとで書く」 | 「あとで書く」が `outline` に `borderWidth: 0`（文字ボタン）。余白 | `Button` README の種別・高さ・余白と比べる |

**書き出しの続きを書く（`WriteScreen`）**

| 項目 | 差の候補 | 直す方向 |
|---|---|---|
| 上の「読み終えた」、タイトル、作者、「あとで」 | 「あとで」の位置（左上）、文字、上余白 | 画像と比べる |
| 「書き出しを選んで、続きを書こう」と書いた数（1 / 3） | `guide` の行揃え・文字 | 画像と比べる |
| 「ひとことで言うと、」の欄 | `OneLinerField` の枠・文字（明朝）・高さ | `TextField` README と比べる |
| `Starter` のカード | 書き出しは朱の太字・明朝で続きと一続きに組む。選択時の見た目。ページ欄と「引用として残す」 | `Starter` README と比べて `Starter` / `StarterText` を直す。`Starter` は `StartersScreen` 等でも使われるため、変えたら該当画面も撮って確認し PR に書く |
| 「↻ ほかの書き出しを見る」「自由に書く」、固定の「ここまでを残す」 | `action` の文字色・間隔、固定バーの余白 | 画像と比べる |

撮影データ（`app/scripts/screenshots/seed.cjs` の `makeFinishedRecord` / `makeWriteRecord`、`scenes.cjs`）が画像と同じ状態でなければシーンを足す。例: finished は評価 4.5・お気に入りオフ/オン、write は「1 / 3」（1 つ書いた下書きまたは入力操作）と選択中カード・ページ・「引用として残す」オン。`scenes.cjs` の `actions` で再現する。既存の scenes テスト（`STORAGE_KEYS` 一致、`recordGuard` 通過）を保つ。

### やらないこと
- `tokens.ts` / `docs/design-system/` / CI 設定の変更。トークンに無い色・文字スタイル・部品が要るときは判断ログに提案する
- 書き込み・保存・下書きのロジック（`lib/writeSession.ts`、`lib/finished.ts`、`lib/ratingWord.ts`）と文言の変更
- この2画面以外の見た目の変更。共通部品（`RatingSlider`、`Toggle`、`Starter`、`Button`、`Shelf`/`Spine`）を直して他画面が変わる場合は、その画面も `pnpm shots` で撮って確かめ、PR に書く。`Shelf`/`Spine` は #117 で済んでいるため原則触らない

## 受け入れ条件

**読み終えた**
- [ ] 背表紙（`Shelf` 上）、「読み終えた」、タイトル、サマリー（期間・日数・メモ件数）が表示される
- [ ] 「どうだった？」と、評価があるときだけ数字と言葉（例「4.5 よかった」）が出る。評価がなければ出ない
- [ ] 言葉の目安（`RATING_GUIDE`）と「星をなぞると 0.1 ずつ変わります」が出る
- [ ] 「お気に入りにする」のトグルを切り替えると保存され、失敗時は元に戻りエラー文言が出る（既存）
- [ ] 「記録を書く」で `onWrite`、「あとで書く」で `onLater` が呼ばれる。ボタンは下に固定され `bottomInset` が余白に足される（既存）
- [ ] 本が見つからないとき「本が見つかりません」と「本棚へ戻る」（既存）

**書き出しの続きを書く**
- [ ] 「読み終えた」、タイトル、作者（あれば）、「あとで」が表示され、「あとで」で `onLater`（下書き保存は既存どおり）
- [ ] 「書き出しを選んで、続きを書こう」と「書いた数 / 設定の数」が出る。書き出しオフのときは数を出さない
- [ ] 「ひとことで言うと、」の欄と `Starter` のカードが設定の数だけ出る。カードを選ぶと選択状態になる
- [ ] 選んだカードにページ欄と「引用として残す」が出る（`Starter` の既存振る舞い）
- [ ] 「ほかの書き出しを見る」「自由に書く」は書き出しオンのときだけ出て、押すと入れ替え・自由欄の追加が起きる
- [ ] 「ここまでを残す」は書いたものがあるときだけ押せ、押すと保存して `onSaved`（既存）

**共通**
- [ ] 撮り直した `finished` / `write` を画像と見比べ、PR 本文に、各画面の「確認する項目」すべてについて 一致 / 直した（何をどう） / 残した（理由）の表を書く
- [ ] 共通部品を直して他画面が変わる場合、その画面を撮って確かめたことを PR 本文に書く
- [ ] `cd app && pnpm check` が通る

## 画面・振る舞い

- 読み終えた: 上から 背表紙＋棚板（中央）→「読み終えた」（朱）→ タイトル → サマリー →「どうだった？」→ 星の入力 → 数字と言葉 → 目安 → お気に入りカード。下に固定の「記録を書く」（主）と「あとで書く」。中央寄せ。
- 書き出しの続きを書く: 上に「あとで」。左揃えで「読み終えた」、タイトル、作者、案内と書いた数、「ひとことで言うと、」、`Starter` カード群、自由欄、「↻ ほかの書き出しを見る」「自由に書く」。下に固定の「ここまでを残す」。キーボードが出ても固定バーが隠れない（既存）。
- 状態遷移・エラー時の振る舞い（保存失敗の文言、読み込み中、本が見つからない）は変えない。見た目だけ。

## テスト方針

| 受け入れ条件 | テスト |
|---|---|
| 読み終えた: 表示要素、評価あり/なしの出し分け、お気に入り切替・失敗、ボタンのコールバック、見つからない | `screens/__tests__/FinishedScreen.test.tsx`（既存を、構造変更に合わせて更新） |
| 書き出し: 見出し・作者・「N / M」、書き出しオフの出し分け、アクション表示条件、保存可否 | `screens/__tests__/WriteScreen.test.tsx`（既存を更新） |

スタイル数値だけを確かめるテストは足さない。変更行の差分カバレッジ 80% 以上（新しい分岐は上のテストで通す）。テストは削らない。

## 判断ログ

- **差を仕様段階で確定しない**: 起動・撮影ができないため、画像と現行コードの読み合わせによる「差の候補」にとどめ、確定は実装担当の撮影に委ねる。却下案: 推測の数値を仕様に固定する（誤りで手戻り）。
- **星の入力は `RatingSlider` のまま**: Issue は `RatingStars` を部品に挙げるが、現行は `RatingSlider`（なぞって 0.1 刻み）で、README の入力仕様（34px・なぞる）と同じ操作。コンポーネントを置き換えず、見た目を README に合わせる。却下案: `RatingStars` に差し替える（入力操作のテスト・触覚フィードバックを作り直す必要があり、見た目だけの Issue を超える）。
- **共通部品は必要最小限だけ直す**: 差が部品起因のときだけ `Toggle`/`Starter`/`Button`/`RatingSlider` を直し、他画面を撮って PR に書く。却下案: 画面側で上書きして部品と画面で見た目を分ける（二重管理になる）。
- **朱の使用**: 「読み終えた」・数字の隣の言葉・書き出しは README が `ribbon` を許す場所。ほかには足さない。
- **新しい色・文字スタイル**: 足さない。必要なら実装担当がここに提案として追記する。
