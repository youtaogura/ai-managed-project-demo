# Issue #117 見た目を直す: 本棚・本棚（本がない）

## 背景・目的

書斎のデザインで作り直した本棚の画面が、`docs/design-system/screens/shelf.png` `shelf-empty.png` と細かいところで違う。`pnpm shots -- shelf shelf-empty` で今の画面を撮り（`app/.screenshots/`）、デザイン画像と見比べて、違いを直す。画像と部品の README が食い違うときは部品の README を優先し、色・余白・角丸・文字は `design/tokens.ts` のトークンで直す。画像の本・作者・文章（サンプル）の違いは直さない。

## スコープ

### やらないこと

- 本棚以外の画面の見た目の変更。ただし `Spine` `Shelf` `Chip` `TabBar` `EmptyState` はほかの画面でも使う共通部品なので、直した結果が変わる画面（振り返りの「今年のお気に入り」、本棚を選ぶシート、タイトルで探す、ほかのタブ画面）も `pnpm shots` で撮って確かめ、PR 本文に書く

## 判断ログ

- **本がない画面の説明文を画像の文言に変えるか**: 変える。画像の本・作者・文章はサンプルだが、この文は画面固有の UI 文言で、README にもサンプルではないと読める。却下案: 今の文言を残す（画像との差が残る）。テストの文言は更新する。
- **栞の描画方法**: View のみ（三角で切り欠き）。却下案: `react-native-svg` の追加（依存追加が要り、1つの形のためには過剰）。`Spine` の栞と凡例を同じ `RibbonMark` にして、形のずれを防ぐ。
- **サブ行「まだ本がありません」**: 画像に書かれているため追加。本がある時は従来どおり「N 冊 · 今年読んだ N 冊」。
- **共通部品の変更の影響**: `Spine`/`Shelf`/`Chip`/`TabBar`/`EmptyState` を直すと他画面が変わる。範囲を広げないよう、直す点は README と画像が一致する点に限り、他画面も撮って PR に書く。
- **背表紙のサイズ**: README の範囲（幅 28〜44、高さ 150〜184）に今の実装が合っているので変えない。画像の違いは本の冊数（2段）による。
- **チップ文字の太さ・タブ選択中の太さ**: トークンの `value`・`body`・`label` から選ぶ。合うトークンが無ければ新しい文字スタイルは作らず、ここに提案として追記する（実装担当が追記）。
