# Issue #161 背表紙の縦書きで「ー」や英数字の向きを直し、長いタイトルは三点リーダで省略する

## 背景・目的

`Spine` はタイトルを 1 文字ずつ縦に積んでいる（`Array.from(title)`）。そのため「ー」「〜」「（」などが横向きのまま、「ONE PIECE」「1Q84」が 1 文字ずつ積まれて読めない。
また高さに収まらないと途中で切れるだけで、省略されたことがわからない。
縦書きの向きを正し、収まらないときは「︙」で省略する。同じ組みを背表紙を使うすべての場所にそろえる。

## スコープ

やること
- タイトルを縦書きの組みの単位（和文 1 文字 / 回す文字 / 英数字のまとまり）に分ける純粋関数
- 収まる範囲を計算し、収まらなければ最後に「︙」を付ける関数
- `Spine` をその結果で描画する（向きの変更は `transform: rotate`）
- 撮影用データ（`app/scripts/screenshots/seed.cjs`）に「ゲーム」「ONE PIECE」「1Q84」「三体 II」の本を足す
- 部品 README（`docs/design-system/components/Spine/README.md`、PR #164）の決まりに従う

やらないこと
- `Spine` の大きさ・色・栞・読み上げラベルの変更
- 縦書き用フォントの追加、新しいライブラリ、トークンの追加（なし）
- 背表紙以外（表紙・カード）のタイトル表示

背表紙を使う場所（`Spine` を使う `Shelf`・`ReadingScreen`・`RecordForm` のプレビュー・`BookSearchRow`）は、`Spine` 1 か所の修正で全部そろう。個別の組み方は持たせない。

## 受け入れ条件

- [ ] `splitVerticalUnits(title)` が単位の配列を返す。種類は `upright`（和文 1 文字）/ `rotate`（回す文字）/ `latin`（英数字のまとまり）/ `tcy`（縦中横）

  - [ ] 「ONE PIECE」→ `ONE PIECE` 1 単位（latin。内側の空白は含める）
  - [ ] 「1Q84」→ `1Q84` 1 単位（latin）
  - [ ] 「三体 II」→ `三` `体` `II`（latin。和文と英数字の間の空白は単位に含めず捨てる）
  - [ ] 「AI 時代の読書」→ `AI`(latin) `時` `代` `の` `読` `書`
  - [ ] 「12」（数字のみ 2 文字以下）→ `12` 1 単位（tcy）。3 文字以上の数字や英数字混在は latin
  - [ ] 「〜」「…」「―」「ー」は rotate。かっこ類（`（）「」『』【】` など）は縦書き用の字形（`︵︶﹁﹂﹃﹄︻︼` など）に置き換えた upright 単位にする
  - [ ] 小さい仮名「ゃゅょっ」は upright のまま、位置ずれ補正用のフラグ（`shift`）を付ける
  - [ ] 空文字は空配列。サロゲートペア（絵文字、𠮷）を壊さない
- [ ] `fitVerticalUnits(units, availableHeight, fontSize, lineHeight)` が、収まる単位と `truncated` を返す

  - [ ] すべて収まるなら `truncated: false`、省略記号なし

  - [ ] 1 単位も入らない高さでも「︙」だけは出し、落ちない
- [ ] `Spine` が上の結果を描画する
  - [ ] 「ゲーム」で「ー」が `rotate: 90deg` の変形つきで表示される（和文は変形なし）
  - [ ] 「ONE PIECE」は 1 つの `Text` にまとめ、全体が `rotate: 90deg`（右に倒す）で表示される。1 文字ずつの `Text` に分かれない
  - [ ] 省略したときだけ「︙」が表示され、収まるタイトルには出ない
  - [ ] 読み上げラベルは従来どおり（タイトル全文。組み替えの影響を受けない）、組んだ文字は読み上げから隠す
  - [ ] 幅 34px 未満（`dimensions={{ width: 30, height: 150 }}`）は文字 12px で組む
- [ ] 撮影用データに 4 冊を足し、`pnpm shots` で撮った画像で向きを確認して PR 本文に書く
- [ ] `pnpm check` が通る。既存の `Spine` / `Shelf` / 各画面テストが（1 文字ずつ `getByText` している箇所を除き）通る

## 画面・振る舞い

- タイトルは背表紙の上端（`TITLE_TOP`）から縦に積む。左右中央そろえ。
- upright: 今までどおり 1 文字。小さい仮名は右上に寄せる（`shift`: 文字サイズの約 0.08 だけ右・上にずらす。定数化）。
- rotate: その 1 文字を `rotate: 90deg`。行の高さ（`lineHeight`）の正方形に収めて中央に置き、積む長さは他と同じ。
- latin: 全体を 1 つの `Text` として 90 度右に回す。回すと「幅」と「高さ」が入れ替わるので、回す前の外枠を `width = 文字数 × fontSize × 0.6`（積む長さ）、`height = lineHeight` とし、`transform: rotate(90deg)` で中央に置く（外側の `View` に回転後の寸法 `width: lineHeight, height: 長さ` を持たせて積む長さを確保する）。
- tcy: 横向きのまま 1 行ぶんの高さに収める（文字サイズは変えない。2 文字で幅が背表紙幅 −（端の陰 2px×2）を超えるときは latin に切り替える）。
- 省略: 収まる分のあとに「︙」（U+FE19）を `rotate` しない 1 単位として置く。縦書き用字形がフォントにない場合に備え、実装時に Shippori Mincho に含まれるか確認し、なければ「…」を `rotate: 90deg` にして代用する（見た目は同じ縦の三点）。
- 表示領域の高さ = `height − TITLE_TOP`。
- エラー状態はない（空タイトルは何も出さない）。

## 設計

追加・変更
- `app/src/lib/spineTitle.ts`（新規）: `splitVerticalUnits` / `fitVerticalUnits` と型 `VerticalUnit = { kind: 'upright' | 'rotate' | 'latin' | 'tcy'; text: string; shift?: boolean }`。React 非依存の純粋関数。かっこの置き換え表・回す文字の集合もここに定数で置く。
- `app/src/lib/__tests__/spineTitle.test.ts`（新規）
- `app/src/components/Spine.tsx`: `Array.from(record.title).map` を、`fitVerticalUnits(splitVerticalUnits(title), height − TITLE_TOP, fontSize, lineHeight)` の結果の描画に置き換える。単位 1 つの描画は同ファイル内の小さなコンポーネント（`SpineUnit`）に出す。
- `app/src/components/__tests__/Spine.test.tsx`: 1 文字ずつ `getByText` するテストを新しい振る舞いに合わせて更新（組む単位が変わるだけで検証内容は残す）
- `app/scripts/screenshots/seed.cjs`: 本棚に「ゲーム」「ONE PIECE」「1Q84」「三体 II」を追加（既存の本は変えない。`scenes` がレコード件数に依存していないか確認する）

分類の規則（`splitVerticalUnits`）
1. `[A-Za-z0-9]` と、その間に挟まれた英数字用の記号・空白（` ` `.` `,` `-` `'` `&` `:` `/` など）のひと続きを latin の候補にする。前後の空白は落とす。末尾が記号のときは含める（「SF!」）。
2. 候補が数字のみで 2 文字以下なら tcy、それ以外は latin。
3. 全角英数字（Ａ１）は和文扱い（upright）。向きを変えない。
4. rotate: `ー ー 〜 ～ … ‥ ― — – −`（長音・波ダッシュ・三点・ダッシュ）。
5. かっこ類は置き換え表で縦書き字形にして upright。
6. 上記以外の文字は upright（和文・記号・絵文字）。和文の間の半角空白は 1 つの空白単位（`upright`、空の 1 行ぶん）にせず捨てる。「サピエンス全史 : 文明…」のコロンは latin 候補だが前後が和文でも単独記号なので、`:` は rotate 扱いにせず latin（1 文字）にする。

状態管理・データ構造の変更はなし。依存の追加はなし。

## 判断ログ

- **英数字の回し方**: Issue どおり、まとまりごと 90 度右に回す。却下案: 1 文字ずつ回す（読めない）、縦積みのまま（現状）。
- **2 文字までの数字は縦中横（tcy）にする**: 「12」「99」は短く、回すより縦中横のほうが日本語の縦書きの慣習に合い、行高 1 つで済む。却下案: すべて回す（1 行ぶん広く取り、短い数字が目立つ）。3 文字以上や英字混在は回す。幅が足りない細い背表紙では latin に落とす。
- **かっこは回さず、縦書き用字形に置き換える**: 回転だと位置が文字枠の端に偏る。置き換え表は小さく、フォントに字形が無い場合のみ回転にフォールバックする（実装で Shippori Mincho の収録を確認し、判断ログに結果を追記する）。却下案: 全部回転（位置がずれる）。
- **「ー」「〜」「…」「―」は回転**: Issue どおり。
- **省略記号は「︙」**: 縦書きの三点リーダ。フォント未収録なら「…」の回転で代用。
- **latin の長さは近似（0.6em/文字）**: React Native では描画前に文字幅を測れない。実測せず固定比率で計算し、ずれても背表紙の `overflow: hidden` が最後の保険になる。却下案: `onTextLayout` で実測（再描画が増え、テストしにくく、棚に並ぶ多数の背表紙で重い）。
- **和文と英数字の間の空白は捨てる**: 縦に積むと空白が不要な隙間になる。latin の内側の空白は保つ。
- **全角英数字は回さない**: 全角は 1 文字 1 マスの和文扱いで、縦に積んでも読める。
- **小さい仮名の補正は軽いずらしのみ**: 縦書き用字形（`vert` feature）は RN で使えないため、右上へ少しずらす。効果が見えにくければ実装で定数を調整してよい。
- **描画の一本化**: 組みは `Spine` の中だけに置き、本棚・振り返り・読んでる本・登録プレビュー・検索の小背表紙は `Spine` を使うので自動でそろう。
- **README（PR #164）**: この作業ブランチ時点では main にまだ入っていない場合がある。入っていれば README の記述を正とし、仕様書と食い違う点は README に従って判断ログに書く。
