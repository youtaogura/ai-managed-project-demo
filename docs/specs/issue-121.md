# Issue #121 見た目を直す: 読んでる本・メモ・引用を書く

## 背景・目的

「読んでる本」（`ReadingScreen`）と「メモ・引用を書く」シート（`NoteSheet`）が、`docs/design-system/screens/reading.png` `note-sheet.png` と違う。`pnpm shots -- reading note-sheet` で今の画面を撮り（`app/.screenshots/`）、画像と見比べて違いを直す。画像と部品の README が食い違うときは部品の README を優先し、色・余白・角丸・文字は `design/tokens.ts` のトークンで直す。画像の本・作者・文章（サンプル）の違いは直さない。撮影シーン `reading` / `note-sheet` は `scripts/screenshots/scenes.cjs` に既にある。

## スコープ

### やること
仕様書作成時に画像・README・コードを読んで見つけた差。実装担当は撮影して確かめ、下に無い差も Issue の「確認する項目」を1つずつ見て、見つけたら直す。

### やらないこと
- `tokens.ts` / `docs/design-system/` / CI の変更。トークンに無い色・文字スタイル・部品が要るときは判断ログに提案する
- メモ・引用の保存・削除・並び順・下書きの保存ロジックの変更（見た目だけ）
- 画面ヘッダーのルーティング（`app/src/app/reading/…`）の変更
- 読んでる本以外の画面の見た目の変更。ただし `BottomSheet` `Button` `Quote` `MemoRow` `Spine` は共通部品。`Quote` / `MemoRow` は読み返す画面（`reread`）、`BottomSheet` は本棚を選ぶ・作る・追加・削除確認などのシートでも使う。直したら該当画面（`reread` `shelf-new` `shelf-pick` `add-sheet` ほか）も撮り、PR 本文に書く
- `Spine` の見た目（#117 で直した）。ここで違いが見つかったら判断ログに記録のみ

## 受け入れ条件

**読んでる本**
- [ ] 「読んでる · M/D から」（開始日なしは「読んでる」）・タイトル・「作者 · 本棚」が出る
- [ ] 「編集」を押すと `onEdit` が呼ばれる。「戻る」で `onBack`
- [ ] 「メモと引用」と「N 件」が出る。0 件のときは案内文が出る
- [ ] メモ（ページ、なければ「—」）と引用（ページ、ひとこと）が出て、押すと編集シートが開く（既存の振る舞い）
- [ ] 「＋ メモ・引用を書く」を押すと NoteSheet が開く
- [ ] 読んでる状態のときだけ「読み終えた」が出て、押すと完了して `onFinished`。失敗するとエラー文が出てボタンは再び押せる。読み終えた本では出ない

**メモ・引用を書く**
- [ ] 本のタイトルと「閉じる」が同じ行に出て、「閉じる」「背景」で閉じる（下書きは残る・既存）
- [ ] 「メモ」「引用」のタブが出て、選択中が `selected`、押すと切り替わる
- [ ] 「ページ」と「なくても大丈夫」が出る。ページは数字のみ・最大桁数（既存）
- [ ] 引用のときだけ朱の線（`quote-line`）と「ひとこと」の入力欄が出る。メモのときは出ない
- [ ] 本文が空だと「残す」は無効。入力すると有効になり、押すと保存して閉じる。失敗時はエラー文
- [ ] 編集のときは「保存する」と削除の入口が出て、削除は確認を経る（既存）
- [ ] `BottomSheet` を使う他のシートの既存テスト（ラベル・ロール）が通る
- [ ] 撮り直した `reading` と `note-sheet` を画像と見比べ、PR 本文に Issue の「確認する項目」の全項目について 一致 / 直した / 残した（理由）の表を書く（共通部品の影響画面を撮ったことも）
- [ ] `cd app && pnpm check` が通る

## 画面・振る舞い

読んでる本: 上に「‹」と「編集」、背表紙＋文字（読んでる・タイトル・作者と本棚）、「メモと引用」と件数、メモ・引用をページ順に、点線の「＋ メモ・引用を書く」。読んでるときだけ下に固定の「読み終えた」。読み込み中・見つからないときの表示は今のまま。

メモ・引用シート: 上の行にタイトルと「閉じる」、種類の切り替え、ページ、本文（引用は線付き・明朝）、引用のみ「ひとこと」、主ボタン。状態遷移（確認画面・エラー）は変えない。

## 設計

変更するファイル（`app/src/`）:
- `screens/ReadingScreen.tsx` — ヘッダー・hero・点線ボタン・下の固定バーの余白と線、文字の種類
- `components/MemoRow.tsx` `components/Quote.tsx` — 余白・行間（`Quote` の線幅・`LINE_GAP` は `NoteSheet` が使うので、export を保つ）
- `components/NoteSheet.tsx` — 切り替え（セグメント）、ページ行、本文の枠と線、ひとことの placeholder 化、フォーカスの枠色
- `components/BottomSheet.tsx` — `showCloseButton` のときタイトル行に「閉じる」の文字ボタンを置く（下の枠ボタンは廃止）
- `components/TextField.tsx` — ページ行のために横並びの形が要るときだけ（他の利用に影響しないよう props を足す）
- `components/Button.tsx` — 文字ボタンの variant が無ければ追加（既存のラベル・ロールを変えない）。要る場合のみ
- 対応する `__tests__/`

状態管理・データ構造の変更なし。**依存の追加なし。** 撮影シーンは既存の `reading` `note-sheet` で足りる。引用の入力状態を撮る必要があれば、`scenes.cjs` に `note-sheet` の `actions` を足す（「引用」タブを押す）か、`note-sheet-quote` を足す（画像は引用の状態）。

## テスト方針

| 受け入れ条件 | テスト |
|---|---|
| 見出し・件数・案内文・編集・戻る・読み終えた（出し分け・失敗） | `ReadingScreen.test.tsx`（既存を維持） |
| メモ・引用の行（ページ「—」、ひとこと） | `MemoRow.test.tsx` `Quote.test.tsx` |
| シートの開閉・タブ・引用の線・ひとこと・無効/有効・保存・削除 | `NoteSheet.test.tsx`（「閉じる」が上の行に移っても `getByRole('button', {name:'閉じる'})` で押せること。ひとことは名前「ひとこと」で取れること） |
| 閉じる・他のシート | `BottomSheet.test.tsx` と、`BottomSheet` を使うシートの既存テスト |
| フォーカスで枠色が変わる（state 分岐） | 数値は確かめず、フォーカス/ブラーでエラーなく入力できることを `NoteSheet.test.tsx` で通す（差分カバレッジ用） |

スタイルの数値だけを確かめるテストは足さない。テストを消す場合（下の枠ボタン「閉じる」前提のものなど）は、PR 本文の判断ログに何を消したか・置き換えたテストを書く。変更行の差分カバレッジ 80% 以上を満たすよう、新しい分岐は上のテストで通す。

## 判断ログ

- **「閉じる」の位置**: 画像・BottomSheet README（見出しと「閉じる」）に合わせ、タイトルと同じ行の文字ボタンにする。却下案: 今の下の枠ボタンを残す（画像と違い、シートが縦に長くなる）。
- **ページなしの表記**: 画像は「p.—」、MemoRow README は「—」。README を優先して「—」のまま（Issue の方針）。
- **「ひとこと」の見出し**: 画像は見出しなしで placeholder。見出しを外し placeholder にするが、アクセシビリティ名は「ひとこと」を保ち、読み上げ・既存テストを壊さない。
- **メモ側の本文**: 画像が引用の状態だけなので、メモは枠付きのまま UI 書体にする。却下案: 引用と同じ枠にそろえる（メモに線は不要で、引用との区別が弱まる）。
- **編集時の「削除」**: 画像に無い。Button README の「取り消せない操作は文字ボタンか枠ボタンで `danger`」に収まるので、今の枠ボタンを残すか文字ボタンにするかは実装担当が撮影して決め、PR に書く。
- **共通部品の影響**: `BottomSheet` の「閉じる」は `showCloseButton` を使うシート全てに効く。意図した変更として、影響画面を撮って PR に書く。
- **引用の太さ**: 画像の引用文は太く見えるが、トークン `quote` の太さに従う（画像から数値を読み取らない）。違いが大きければトークン追加を判断ログに提案する。
