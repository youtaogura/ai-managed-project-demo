# Issue #184 読み返す画面で「この本をひとことで」・どうだった？・お気に入りを直せるようにする

## 背景

「この本をひとことで」（`oneLiner`）・どうだった？（`rating`）・お気に入り（`favorite`）は、読み終えた画面と読後メモを書く画面でしか入れられなかった。
読み返す画面（`screens/RereadScreen.tsx`）は表示するだけで、あとから直す手段がなかった。

デザイン（`docs/design-system/screens/README.md` の「読み返す」「この本をひとことで・どうだった？を直す」、`reread.png` `oneline-edit.png`）どおりに、
ひとことか星の行を押すと直すシートが開くようにする。まだリリースしていないので、保存データの移行・後方互換は考えない。

## 受け入れ条件

- [x] 読み返す画面で「この本をひとことで」を押すと、直すシートが開く（`RereadScreen.test.tsx`）
- [x] 星・数字・言葉・「お気に入り」の印の行を押しても、同じシートが開く（`RereadScreen.test.tsx`）
- [x] シート: 上に本のタイトルと「閉じる」、「この本をひとことで」の入力欄、「どうだった？」の `RatingSlider`（なぞって 0.1 刻み）と数字・言葉、「お気に入り」の `Toggle`、「保存する」（`RereadScreen.test.tsx`）
- [x] 直して保存すると、読み返す画面と本棚（背表紙の栞）に反映される（`RereadScreen.test.tsx`、`records-routes.test.tsx`）
- [x] どうだった？は「星をなしにする」で未入力に戻せる（判断ログ）（`RereadScreen.test.tsx`、`reread.test.ts`）
- [x] ひとことも星もお気に入りもない本にも入口（「＋ この本をひとことで」）がある（`RereadScreen.test.tsx`）
- [x] 読みたい本では直せない（表示だけ・入口なし）（`RereadScreen.test.tsx`）
- [x] 撮影シーン `oneline-edit` にシートを開く操作を足し、`pnpm shots -- oneline-edit reread reread-empty` で撮って画像と見比べる（下の「見た目の確認」）

## 設計

### 読み返す画面（`screens/RereadScreen.tsx`）

| 部分 | 中身 |
|---|---|
| ひとこと | あるときは今の表示（`one-line`、「」付き）を押せるようにする（`accessibilityRole="button"`、ラベル「この本をひとことで ＋本文」） |
| 星の行 | 星・数字・言葉かお気に入りがあるとき、今の表示の行全体を押せるようにする。ラベルは「どうだった？ 4.2 よかった、お気に入り」のように中身を読む。押せる高さを `touch-min` 以上にした |
| 入口（何もないとき） | ひとこと・星・お気に入りのどれもない本だけ、ひとことの場所に「＋ この本をひとことで」（`button`・`text-secondary`、高さ `touch-min`）を出す |
| シート | どこから押しても同じ `OneLineSheet` を開く |

- 直せるのは、読後メモの段を出す本（読みたい本 `planned` 以外）だけ。読みたい本でもひとこと・星が残っていれば表示はするが、押せない（`Editable` が `onPress` なしのときはただの `View`）
- ひとことがなく星だけある本（`reread-empty.png`）は、星の行が入口になる。そこに「＋ この本をひとことで」は足さない（デザインのまま）

### 直すシート（`components/OneLineSheet.tsx`）

- `BottomSheet`（`showCloseButton` + `closeInTitleRow`）。上に本のタイトルと「閉じる」。読後メモを直すシートと同じ組み
- 「この本をひとことで」: 見出し `value`・`text-secondary`。入力欄は `NoteSheet` の `FocusInput`（フォーカス中は枠 `text-primary`）、`one-line` の明朝、面 `surface-1`、高さ `one-line` 2 行ぶん
- 「どうだった？」: 見出しの右に「星をなぞると 0.1 ずつ変わります」（`label`・`text-secondary`）。`RatingSlider`（34px、0.1 刻み、整数の境目で触覚）。右に数字（`display-number`）と言葉（`ribbon` の明朝 `reading`）。未入力なら「まだ選んでいません」
- 「星をなしにする」: 星が入っているときだけ、星の行の下に小さく（`label`・`text-secondary`、タップ領域 `touch-min`）
- 「お気に入り」: `ToggleRow`。読み終えた画面の「お気に入りにする」と同じ枠付きの行
- 「保存する」: 押すと `updateOneLine(record, values)` → `repository.update`。成功で閉じ、失敗ならシートにエラーを出して入力を残す
- 「閉じる」・後ろのタップ・スワイプでは保存しない（直すシートなので下書きは持たない）

### 保存用の関数（`lib/reread.ts`）

- `updateOneLine(record, { oneLiner, rating, favorite }): NewRecordInput` — `recordToInput` でほかの項目を残し、3 つだけ差し替える。ひとことは前後の空白を除き、空なら `null`

### 撮影シーン

- `oneline-edit` に、ひとこと（「「宇宙はとても静かで、とても怖い。」」）を押す操作を足し、「星をなぞると 0.1 ずつ変わります」を待って撮る

## 判断ログ

| 判断 | 選んだ案 | 却下した案 | 理由 |
|---|---|---|---|
| どうだった？を未入力に戻せるか | 戻せる。星が入っているときだけ、星の下に小さく「星をなしにする」を出す | 戻せない（1.0〜5.0 のどれかを選ぶだけ） | 読み終えた画面は星に触れた瞬間に保存されるので、うっかり触れただけでも点が付く。読み返す画面で外せないと、振り返りの分布に意図しない点が残り続ける。デザインにない部品なので、目立たない文字の操作にした（デザインの持ち主への提案: シートの画像に「星をなしにする」の位置を描き足してほしい） |
| 「星をなしにする」の言葉 | 「星をなしにする」 | 「クリア」「評価を消す」「まだ決めない」 | 「評価」は書き方で使わない言葉。「クリア」は硬い。「まだ決めない」は押した結果（星が消える）が伝わりにくい |
| 何もない本の入口 | ひとこと・星・お気に入りがどれもないときだけ、ひとことの場所に「＋ この本をひとことで」 | 星の行を空の星（「まだ選んでいません」）でいつも出す／ひとことがなければいつも案内を出す | `reread-empty.png` はひとことなし・星ありで、案内を描いていない。星の行があればそれが入口になるので、何もないときだけ足せば画像と食い違わない。空の星をいつも出すと、点の付いていない本が「点を付け忘れた本」に見える |
| 入口の見た目 | 「＋ 読後メモを書く」と同じ書き方（`button`・`text-secondary`）の文字だけ、点線の枠なし | 点線のボタン | 点線のボタンは段の終わりの「書く」入口に使っている。上部に点線を足すと、ひとことが読後メモの段と同じ重さに見える。デザインにない部分なので小さく留めた |
| 直せる本 | 読みたい本以外（読んだ・途中でやめた） | 読み終えた本だけ | 読後メモの段（#183）と揃える。途中でやめた本にも点やひとことを残したい人はいる |
| 読みたい本にひとこと・星が残っているとき | 表示だけで押せない | 押せる／表示しない | Issue の「読みたい本には当てはめない」に従う。表示は今のまま残し、編集でステータスを戻せばまた直せる |
| シートの作り | 新しい `OneLineSheet` | `PostReadMemoSheet` に項目を足す、読み終えた画面の部品を切り出す | 項目と保存の仕方（3 つをまとめて保存）が違う。読み終えた画面は押すたびに保存する作りで、シートの「保存する」で確定する形と合わない。入力欄の `FocusInput`、`RatingSlider`、`ToggleRow` は共有して見た目を揃えた |
| 保存のしかた | 「保存する」で 3 つまとめて保存 | 読み終えた画面のように触れるたびに保存 | デザインに「保存する」がある。「閉じる」で取り消せるほうが、あとから直す場面では安心 |
| シートを開いたときのフォーカス | 入力欄にフォーカスしない | 開くと入力欄にフォーカス（読後メモを直すシートと同じ） | 星の行から開いたとき、キーボードで星とお気に入りが隠れる。ひとことを直したい人は入力欄を押せばよい |
| 言葉の書体 | 明朝（`reading`、`ribbon`） | 画像のゴシック太字 | RatingStars/README が「言葉を `ribbon` の明朝で添える」。読み終えた画面とも揃う。README を優先した |
| 入力欄の面 | `surface-1`（枠 `line`） | 画像の少し暗い面 | TextField/README が `surface-1`。読後メモを直すシートとも揃う |
| 星の行の高さ | `touch-min`（44）以上 | 今の高さ（お気に入りの印の高さ） | 押せるものは 44 以上（CLAUDE.md）。上下に数 px 広がるだけ |
| 何もない本の入口のアクセシビリティラベル | 「この本をひとことで」 | 「この本をひとことでを書く」 | 見出しと同じ言葉のほうが短く伝わる。ボタンとして読まれる |
