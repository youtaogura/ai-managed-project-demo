# Issue #139 読み返す画面から開いた書き出しの「あとで」で本棚に戻ってしまう

## 背景・目的
`app/write/[id].tsx` は「あとで」（`onLater`）を常に `router.replace('/')` にしている。
そのため読み返す画面（`/records/<id>`）から `router.push('/write/<id>')` で開いても、「あとで」で本棚に移り、元の読み返す画面に戻らない。
開いた元の画面に戻るようにする。

## スコープ
やること
- 読み返す画面から開いた書き出しの続きで「あとで」（画面上のボタンと Android の戻るキー、どちらも `onLater`）を押すと、読み返す画面に戻る。
- 読み終えた直後（`/finished/<id>` →「記録を書く」）から開いたときの行き先は、仕様として「本棚（`/`）」で固定する。

やらないこと
- `WriteScreen` 本体、下書き保存の挙動、見た目の変更。新しい依存・トークンの追加。
- 「ここまでを残す」（保存）後の行き先の変更（今までどおり `/records/<id>`）。

## 受け入れ条件
- [ ] 読み返す画面（`/records/r1`）→「書き出しの続きを書く」→ 何もせず「あとで」を押すと、パスが `/records/r1` に戻り、読み返す画面が表示される（Jest、ルート結合テスト）。
- [ ] 読み返す画面から開いた書き出しの続きで、下書きがある状態で「あとで」を押しても下書きは保存され、読み返す画面に戻る。
- [ ] 読み終えた直後（`/finished/r1`）→「記録を書く」→「あとで」を押すと、本棚（`/`）に移る（Jest）。
- [ ] `/write/r1` を直接開いた（戻る先の履歴がない）ときの「あとで」は、本棚（`/`）に移る（Jest）。
- [ ] 「ここまでを残す」後は今までどおり `/records/r1` に移る（既存テスト）。

## 画面・振る舞い
- 読み返す画面から開いたとき: 「あとで」→ 読み返す画面。戻ると画面は元のスクロールや表示のまま（履歴を 1 つ戻るため）。
- 読み終えた直後: 「あとで」→ 本棚。同じ画面群の「あとで書く」（本棚へ）と行き先がそろう。
- 履歴がない（直接開いた）とき: 本棚。
- エラー時の振る舞いは変更なし。

## 設計
行き先は「開いた元」を表すクエリパラメータ `from` で渡す。
- `app/src/app/records/[id].tsx`: `onWrite` を `router.push({ pathname: '/write/[id]', params: { id: recordId, from: 'reread' } })` にする。
- `app/src/app/write/[id].tsx`: `useLocalSearchParams<{ id: string; from?: string }>()` で `from` を読む。
  `onLater` は `from === 'reread' && router.canGoBack()` のとき `router.back()`、それ以外は `router.replace('/')`。
  `from` は型ガード（文字列かつ `'reread'` と一致）で絞り込み、それ以外の値は無視する。
- `app/src/app/finished/[id].tsx`: 変更なし（`from` を付けない → 本棚）。
- `WriteScreen` は変更しない（`onLater` を呼ぶだけ）。

## テスト方針
`app/src/__tests__/finished-write-route.test.tsx`（`renderRouter`）に追加する。
- 読み返す画面から「あとで」→ `/records/r1`（受け入れ条件 1, 2）
- 読み終えた直後から「あとで」→ `/`（条件 3）
- `/write/r1` 直接 →「あとで」→ `/`（条件 4）
- 既存の「ここまでを残す」テスト（条件 5）

## 判断ログ
- **読み終えた直後の行き先**: 本棚のまま固定。却下: 読み返す画面に移す案。まだ何も書いていない本の読み返す画面は空の状態で、読み終えた画面の「あとで書く」（本棚）ともずれる。
- **戻り方**: `router.back()`（履歴を戻す）＋ 履歴がなければ本棚。却下: 常に `router.replace('/records/<id>')`。読み返す画面が履歴に二重に積まれる。
- **元の画面の伝え方**: クエリパラメータ `from=reread`。却下: `canGoBack()` だけで判断する案。読み終えた直後は `replace` で開くので履歴に何があるか不定で、意図しない画面に戻りうる。
