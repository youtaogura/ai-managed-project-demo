# 画面デザイン（書斎）

アプリの画面のデザイン。画像は幅 390px（2倍で書き出し）。縦に長い画面は、スクロールしきった全体を1枚にしている。

- 画面を作る・変えるときは、該当する画像と下の説明を見て、その見た目に合わせる。
- 色・文字・余白・角丸は画像から読み取らず、`app/src/design/tokens.ts` のトークンを使う。
- 使う部品は `../components/`（Spine、Shelf、Starter、Quote、MemoRow、RatingStars、Button、Chip、Toggle、TextField、BottomSheet、TabBar、EmptyState）。**画像と部品の README が食い違うときは、部品の README を優先する。**
- 画像の本・作者・文章はサンプル。`[出版社名]` `[ISBN]` は実際の値が入る場所。
- 元データは claude.ai のデザインキャンバスの「読後ノート 全画面（案1）」ページ。直したら、ここの画像も書き出し直す。

## 前のデザインから変わる点（まとめ）

| 変わる点 | 前 | 書斎 |
| --- | --- | --- |
| 扱うもの | 本・漫画・映画・ドラマ・アニメ | **本だけ**（漫画も本として扱い、区別しない） |
| 一覧 | 書影の4列グリッド、大きく出す作品の横並び | **背表紙の棚**。上部で本棚（すべての本／自分で作った本棚）とステータスを切り替える |
| 本の分類 | 種別 | **本棚（タグ）**。1冊を複数の本棚に入れられる |
| 書影 | 主役 | 使わない（背表紙の色を本ごとに選ぶ） |
| 感想 | 自由記述の1欄 | **書き出しの続き**、引用、メモ、ひとこと、自由に書く |
| 評価 | 「評価」と数字 | 「どうだった？」と数字＋言葉（最高・よかった・まあまあ・あんまり） |
| 勧めたい | 「人に勧めたい」 | **お気に入り**（背表紙に朱の栞） |
| 詳細画面 | 書影が主役 | **読み返す画面**（ひとこと → 書き出しの続きと引用 → メモ） |
| 地の色 | 黒 | 生成りの紙 |
| 設定 | 使う種別、記録する項目、大きく出す作品 など | 書き出し、ステータスの初期値、本棚の管理、並び順、データ、このアプリについて |

## 本棚と本を追加

### 本棚 — `shelf.png`

![](shelf.png)

- 見出し「本棚」（`screen-title`）と「64 冊 · 今年読んだ 48 冊」。右上に丸い追加ボタン。
- 本棚の切り替え（`Chip` の切り替え）: 「すべての本」「SF」「哲学」…、最後に「＋ 本棚を作る」。
- ステータスの絞り込み（下線のタブ）: 「すべて」「読んでる」「読んだ」「読みたい」と件数。初期値は「すべて」。
- 凡例は「お気に入り」（栞）だけ。
- `Shelf` に `Spine` を並べる。背表紙をタップすると、読んでる本は「読んでる本」、それ以外は「読み返す」へ。

### 本棚（本がない） — `shelf-empty.png`

![](shelf-empty.png)

- `EmptyState`: 点線の空の背表紙、「最初の1冊を、棚に並べよう」、「本を追加する」。

![](shelf-new.png)

![](add-sheet.png)

### 本を登録・編集 — `book-form.png`

![](book-form.png)

- 上に背表紙のプレビューと「背表紙の色」（`spine-1`〜`spine-10` の丸から選ぶ）。
- タイトル（必須・明朝）、作者、出版社、ISBN、ステータス（`Chip` 単一選択）、読み始めた日・読み終えた日、本棚（`Chip` 複数選択）。
- 感想・評価・写真はここで入力しない（読み終えたときと、読み返す画面で扱う）。
- 下に固定: 追加は「棚に並べる」、編集は「保存する」。編集のときは一番下に「この本を削除」（`danger` の文字ボタン）。

## 読む・読み終える・読み返す

### 読んでる本 — `reading.png`

![](reading.png)

- 上に背表紙と、「読んでる · 10/18 から」（`ribbon`）、タイトル（`book-title`）、「作者 · 本棚」。右上に「編集」。
- 「メモと引用」と件数。`MemoRow` と `Quote` をページ順に並べる。
- 「＋ メモ・引用を書く」（点線ボタン）。
- 下に固定の主ボタン「読み終えた」。

### メモ・引用を書く — `note-sheet.png`

![](note-sheet.png)

- `BottomSheet`。上に本のタイトルと「閉じる」。
- 「メモ」「引用」の切り替え。ページ（任意、「なくても大丈夫」）。
- 本文: 引用のときは左に `ribbon` の線、明朝。メモのときは UI の書体。
- 引用のときは「ひとこと（任意）」。主ボタン「残す」。

### 読み終えた — `finished.png`

![](finished.png)

- 「読み終えた」を押したあとの画面。背表紙と棚板、「読み終えた」（`ribbon`）、タイトル、「10/18 – 10/26 · 9 日間 · メモ 4 件」。
- 「どうだった？」: `RatingStars` の入力、数字と言葉（「4.5 よかった」）、言葉の目安。
- 「お気に入りにする」（`Toggle`）。
- 下に固定: 主ボタン「記録を書く」（書き出しの続きを書く画面へ）、「あとで書く」。
- 読み終えた日には今日を入れる（ここでは表示だけ。変えたいときは編集で）。

### 書き出しの続きを書く — `write.png`

![](write.png)

- 「読み終えた」、タイトル、作者。「書き出しを選んで、続きを書こう」と、書いた数（1 / 3）。
- 一番上に「ひとことで言うと、」の欄。その下に `Starter` のカードを設定の数だけ。
- 「↻ ほかの書き出しを見る」（オンの書き出しから入れ替える）、「自由に書く」（書き出しなしの欄を足す）。
- 上の「あとで」で閉じても、書いた分は残る。下に固定の主ボタン「ここまでを残す」。
- 設定で書き出しをオフにしているときは、「ひとことで言うと、」と自由に書く欄だけ。

### 読み返す — `reread.png`

![](reread.png)

- 本の画面（読み終えた本）。人に勧める前に、30 秒で思い出せることが目標。
- 上: タイトル（明朝・`text-secondary`）、「作者 · 読んだ期間」。右上に「編集」。
- ひとこと（`one-line`、「」付き）を一番大きく。
- 星・数字・言葉（「4.2 よかった」）と、お気に入りなら「お気に入り」の印。
- 区切り線の下に、書き出しの続き（`Starter` の組み方。罫線付き）と引用（`Quote`）を、書いた順に。自由に書いた文章も同じ流れで。
- 区切り線の下に「メモ」（`MemoRow`、ページ順）。
- 下の方に「本棚」（この本が入っている本棚。タップで本棚を選ぶシート）、「書き出しの続きを書く」（あとから足せる）。

## 振り返りと設定

### 振り返り — `review.png`

![](review.png)

- 見出し「振り返り」と期間（直近 12 か月）。
- 3つの数字: 読んだ（冊）、感想（書き出しの続きを1つ以上書いた本の数）、引用。
- 「月ごとに読んだ本」: 1冊を1段にして、その本の背表紙の色で積み上げる。今月のラベルだけ墨。
- 「今年のお気に入り」: お気に入りの本を `Shelf` で並べる。
- 「どうだった？」: 平均（数字と言葉）と、最高・よかった・まあまあ・あんまり の冊数（いちばん多い段だけ墨）。
- 「今年いちばん使った書き出し」と回数。

### 設定 — `settings.png`

![](settings.png)

- 「読み終えたら」: 書き出し（「オン · 一度に 3 つ · 7 個から」）、ステータスの初期値。
- 「本棚」: 本棚の管理（名前の変更・並べ替え・削除）、並び順。
- 最後のカード: データ（書き出し・読み込み・すべての記録を削除）、このアプリについて。
- データ・書き出し・読み込み・すべての記録を削除・このアプリについての各画面は、今の実装の構成のまま、見た目だけ書斎のトークンに合わせる（画像なし）。

### 書き出しの管理 — `starters.png`

![](starters.png)

- 「読み終えたら書き出しを出す」（`Toggle`、オフで自由に書く欄だけ）。
- 「一度に出す数」（2・3・5、`Chip` 単一選択）。
- 書き出しの一覧（明朝）と、それぞれの `Toggle`。「ひとことで言うと、」は「固定」でオフにできない。自分で足したものには「自分で追加」。
- 「＋ 自分の書き出しを追加」。自分で足したものは、名前の変更と削除ができる。
