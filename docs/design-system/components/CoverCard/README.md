# CoverCard

記録を書影・ポスター・写真で表す、一覧の基本部品。

## 大きさ

| 大きさ | 使う場所 | 幅 | 角丸 | 下に出す情報 |
| --- | --- | --- | --- | --- |
| `hero` | 「最近読み終えた・見終えた」の横並び | `hero-card-width`（150px） | `radius-card` | 星の数字と終了日 |
| `thumb` | すべての記録の4列グリッド | 列幅 | `radius-thumb` | なし |

縦横比は常に 2:3。

## 受け取る値

- 画像（自分の写真、または書影 URL）。なければ文字の表紙を作る
- タイトル、作者・監督など（文字の表紙に使う）
- 種別（文字の表紙の色を決める）
- ステータス（「読んでる／見てる」のときだけ左上に `accent` の点を出す。点には「読んでる」などの読み上げラベルを付ける）
- 評価、終了日（`hero` のみ）

## 決まり

- 画像の上に文字を重ねない。文字の表紙だけは例外。
- 影は付けない（一覧では書影を詰めて並べるため）。
- タップで詳細画面へ。押した瞬間に少し縮む（scale 0.97、100ms）。
