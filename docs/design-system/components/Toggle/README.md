# Toggle

オン・オフを切り替えるスイッチ。設定の「記録する項目」に使う。

| 状態 | つまみの通り道 | つまみ |
| --- | --- | --- |
| オン | `accent` | `accent-ink` |
| オフ | `line-strong` | `text-tertiary` |

- 大きさは 51×31、つまみは 25px の円（端末の標準のスイッチに近い大きさ）。行全体（高さ 52px 以上）をタップ領域にする。
- 行の左にラベル（`body`）と、必要なら補足（`micro`・`text-tertiary`）。
- 切り替えは 150ms ほどでつまみが滑る。「動きを減らす」がオンなら動きなしで切り替える。
- 読み上げではスイッチとして扱い、ラベルとオン・オフを伝える。
- 端末標準の `Switch` を使う場合も、色はこの表に合わせる。
