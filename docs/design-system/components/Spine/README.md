# Spine（背表紙）

本棚に並べる本の背表紙。書影の代わりに、本を表す基本の部品。

- 幅 `spine-width-min`〜`spine-width-max`、高さ `spine-height-min`〜`spine-height-max`。**本の ID から決める**（同じ本はいつも同じ大きさ。並べ替えても変わらない）。
- 面は、本に設定した `spine-1`〜`spine-10` のどれか。初期値は登録順に割り当てる。上の角だけ `radius-thumb`。
- 左右の端に細い陰（内側に 2px、左を明るく・右を暗く）を付けて、厚みを感じさせる。上から 22px のところに `spine-ink` の細い線（不透明度 0.3）。
- タイトルは `spine-title`・`spine-ink`、縦書きで上から。背表紙の高さに収まらない分は切る（省略記号は付けない）。幅 34px 未満の背表紙では文字を 12px にしてよい。
- **お気に入りの本だけ、朱（`ribbon`）の栞を付ける**: 背表紙の中央の上端から、幅 8px・長さ 22px、下の端を V 字に切り欠いた形で、上に 6px はみ出す。
- ステータス（読みたい・読んでる・読んだ）で見た目は変えない。
- タップでその本の画面へ（読んでる本は「読んでる本」、読み終えた本は「読み返す」）。押した瞬間に少し持ち上がる（translateY -4px、100ms）。
- 読み上げラベルは「<タイトル>、<作者>、<ステータス>」。お気に入りなら「お気に入り」を足す。
