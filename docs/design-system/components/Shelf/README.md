# Shelf（本棚）

背表紙を棚板に並べる部品。本棚の画面、本棚を選ぶシートの背景、振り返りの「今年のお気に入り」で使う。

- 背表紙を、間隔 3px で左から下揃えに並べ、棚1段の幅（画面の幅 − 左右 `space-4`）に収まる数で折り返す。
- 段の下に棚板（`shelf-board`、高さ `shelf-board-height`、角丸 2px、下に `shadow-cover`）。段と段の間は 30px。
- 並び順は設定の「並び順」に従う（初期値は読み終えた日の新しい順。読み終えていない本は登録日時）。
- 本が多いときは縦にスクロールする。1段ずつ描けばよい（仮想化は件数が増えてから検討）。
- 本がないときは `EmptyState`（点線の空の背表紙が並んだ棚）。
