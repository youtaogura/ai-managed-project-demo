# InfoCell

詳細画面で、ステータスと開始日・終了日を小さな面に並べて見せる部品。

- 3つを横に等幅で並べる（ステータス／始めた日／終えた日）。間隔 `space-2`。
- 面 `surface-2`、角丸 `radius-card`、内側の余白 10px × 12px。
- 見出しは `micro`・`text-secondary`、値は `value`・`text-primary`。
- 見出しの文言は種別で切り替える（本・漫画は「読み始めた／読み終えた」、映像は「見始めた／見終えた」）。
- 日付が未入力のセルは値を「—」にする。セルは消さない（並びを崩さない）。
- タップで、その項目を編集する画面を開く。
