# RatingStars

1.0〜5.0・0.1刻みの評価を、部分的に塗った5つの星で表す部品。表示用と入力用がある。

## 表示用

- 星は `accent`、未到達部分は `star-off`。4.2 なら4つ塗り、5つ目を左から20%塗る。
- 隣に数字を置く。詳細画面では `display-number`、一覧では `value`。
- 未評価のときは星をすべて `star-off` にし、数字の代わりに「未評価」（`label`、`text-secondary`）。
- 星全体を1つの画像として扱い、「レーティング 4.2」と読み上げる。

## 入力用（#25）

- 星の上をドラッグすると、指の位置に応じて 0.1 刻みで値が変わる。タップでもその位置の値になる。
- 整数の境目（2.0、3.0…）を越えるとき、ごく軽い触覚フィードバック。
- ±0.1 の微調整ボタン（`touch-min` の丸ボタン）と、「クリア」を横に置く。
- 星の上でのドラッグ中は、画面を縦にスクロールさせない。
- スクリーンリーダーでは「調整可能」な要素として 0.1 ずつ増減できる。
- 入力用の星は表示用より大きく（1つ 36px 以上）、指で狙いやすくする。
