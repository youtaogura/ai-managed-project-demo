# RatingStars（評価）

星 5 つで 1.0〜5.0 を 0.1 刻みで表す。**「評価」という言葉は画面に出さない。** 見出しは「どうだった？」。

- 星は `accent`（墨）、未到達は `star-off`。0.1 刻みで星を部分的に塗る。
- 数字（`display-number`）の横に、言葉を `ribbon` の明朝で添える:

| 点数 | 言葉 |
| --- | --- |
| 5.0 | 最高 |
| 4.0〜4.9 | よかった |
| 3.0〜3.9 | まあまあ |
| 2.9 以下 | あんまり |

- 入力（読み終えた画面）: 星を 34px で。なぞって 0.1 刻み、整数の境目で触覚フィードバック。下に「星をなぞると 0.1 ずつ変わります」。
- 表示（読み返す画面）: 星 16px と数字・言葉を1行で。
- 振り返りの分布は、この4つの言葉で集計する。
