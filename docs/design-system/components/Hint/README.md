# Hint（読後メモのヒント）

読後メモを書くときに、書き始めの手がかりとして差し出す短い文。「いちばん心に残ったのは、」のように、読点で終わる。

**読後メモを書く画面**

- 大きな入力欄（読後メモ）の下に、ヒントを 3 つ、丸いボタン（`radius-full`、面 `surface-1`、枠 `line`、文字は明朝 `starter` の大きさで `text-primary`、右に「＋」）で並べる。
- 押すと、入力欄の今の文章の**最後に改行してから**その文を入れ、カーソルをその後ろに置く。入力欄が空なら改行せずに入れる。
- 一度入れたヒントは、面 `surface-2`・右に「✓」にする（もう一度押しても入れられる）。
- 「↻ ほかのヒント」で 3 つを入れ替える。
- キーボードを開いているあいだは、ヒントの行をキーボードのすぐ上に出す（入力欄と一緒にスクロールしない）。
- 入れた文はユーザーの文章の一部。保存したあとは、ヒントから入れた部分とユーザーが書いた部分を区別しない（データにもヒントの情報を残さない）。

**ヒントの一覧（固定。設定で変えることはできない）**

| 種類 | ヒント |
|---|---|
| 感じたこと | いちばん心に残ったのは、／思わず読む手が止まったのは、／意外だったのは、／読み終えて、最初に浮かんだのは、／少し引っかかったのは、 |
| 中身 | この本をひとつの場面で表すなら、／作者がいちばん伝えたかったのは、たぶん／いちばん好きな登場人物は、／いちばん役に立ちそうなのは、 |
| 自分ごと | 自分のことのように感じたのは、／読み終えて、見方が変わったのは、／明日から試してみたいのは、／昔の自分に読ませたいのは、なぜなら |
| つながり | 似ていると思ったのは、／この本の次に読みたいのは、 |
| 人に勧める | この本を渡したいのは、／まだ読んでいない人に言いたいのは、／この本のいいところを一つだけ言うなら、 |
| 合わなかったとき | 合わなかったのは、／期待していたのとちがったのは、／それでも残ったのは、 |

**出し方**

- 一度に 3 つ。「感じたこと」から 1 つ、「中身・自分ごと・つながり」から 1 つ、「人に勧める」から 1 つ、それぞれランダムに選ぶ。
- 「どうだった？」が「あんまり」（2.9 以下）の本では、「中身・自分ごと・つながり」の 1 つの代わりに「合わなかったとき」から 1 つ出す。
- 「↻ ほかのヒント」は、同じ決まりで、今出ているものと別のものを選ぶ。
