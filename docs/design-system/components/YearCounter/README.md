# YearCounter

> **廃止予定。** 書斎のデザイン（背表紙の棚と読み返す画面）では使わない。画面を作り替えるときに置き換えて、使われなくなったら消す。

一覧の上部で、今年の作品数を大きく見せる部品。積み上がりを感じさせる一番大事な数字。

- 「今年」（`label`・`text-secondary`）、数字（`display-number` 相当の 30px・900・`accent`）、「作品 · 今月 6」（`label`・`text-secondary`）を1行に並べる。
- 記録を完了したとき、数字は 1 ずつ数え上がる動き（300ms 以内）で増える。
- 節目（10・50・100作品）を越えたときだけ、数字の横に「50作品」の小さな印を数日間出す。全画面の演出はしない。
