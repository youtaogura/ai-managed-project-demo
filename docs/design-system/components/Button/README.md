# Button

画面の操作に使うボタン。主ボタン・枠ボタン・丸いアイコンボタンの3種類。

| 種類 | 面 | 文字・アイコン | 大きさ | 使う場所 |
| --- | --- | --- | --- | --- |
| 主ボタン | `accent` | `accent-ink` | 高さ `button-height`、角丸 `radius-button` | 「編集」「保存」など、その画面で一番大事な操作。1画面に1つ |
| 枠ボタン | なし（枠 `line-strong`） | `text-primary` | 主ボタンと同じ | 「作品の情報」など、それ以外の操作 |
| 丸いアイコンボタン | `surface-2`（画像の上では `scrim`） | `text-primary` | `touch-min` の円 | 並び替え、戻る、写真の変更 |
| 記録ボタン | `accent` | `accent-ink` | `touch-min` の円 | 一覧の右上。「記録する」と読み上げる |

## 決まり

- 押した瞬間に少し暗く・小さくする（不透明度 0.8、scale 0.97、100ms）。
- 削除などの取り消せない操作は枠ボタンにし、文字と枠を `danger` にする。確認は画面内で行う。
- アイコンだけのボタンには読み上げ用のラベルを付ける。
