# Button

| 種類 | 面 | 文字 | 大きさ | 使う場所 |
| --- | --- | --- | --- | --- |
| 主ボタン | `accent`（墨） | `accent-ink` | 高さ `button-height`、角丸 `radius-card` | 「記録を書く」「棚に並べる」「残す」など、その画面で一番大事な操作。1画面に1つ。画面の下に固定することが多い |
| 枠ボタン | なし（枠 `text-primary`） | `text-primary` | 主ボタンと同じ | 「見つからないので手で入力する」など |
| 点線ボタン | なし（点線の枠 `text-tertiary`） | `text-secondary` | 高さ 44px | 「＋ メモ・引用を書く」「＋ 本棚を作る」など、追加の入口 |
| 文字ボタン | なし | `text-secondary` | 高さ 44px 以上 | 「あとで書く」「閉じる」「編集」 |
| 丸い追加ボタン | `accent` | `accent-ink` | `touch-min` の円 | 本棚の右上の「本を追加」 |

- 押した瞬間に少し暗く・小さくする（不透明度 0.8、scale 0.97、100ms）。
- 取り消せない操作は文字ボタンか枠ボタンで、文字と枠を `danger` にする。
