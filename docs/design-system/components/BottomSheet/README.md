# BottomSheet

画面の下からせり上がる面。追加の入口（「何を記録しますか」）、並び替え、削除の確認に使う。

- 面 `surface-1`、上の角丸 20px、上端中央につまみ（36×4、`line-strong`）。下はセーフエリアの分だけ余白を足す。
- 後ろは `scrim` で暗くする。後ろのタップ、下へのスワイプ、閉じるボタン（あれば）で閉じる。
- 見出しは `section-title`。中身の左右の余白は `space-6`。
- 開くときは下から 250ms ほどで減速しながら出る。「動きを減らす」がオンならフェードだけ。
- 読み上げではダイアログとして扱い、開いている間は後ろの画面に読み上げのフォーカスが移らないようにする。
- 削除の確認では、閉じる操作は「キャンセル」と同じ扱いにする。

角丸 20px とつまみの大きさはトークンにない。実装時に仕様書の判断ログでトークン化を提案し、追加されるまではこの部品の中だけで定数にしてよい。
