# BottomSheet

画面の下からせり上がる面。本を追加、本棚を選ぶ、本棚を作る、メモ・引用を書く、削除の確認などで使う。

- 面 `surface-1`、上の角 `radius-sheet`、上端中央につまみ（36×4、`line`）。下はセーフエリアの分だけ余白を足す。
- 後ろは `scrim` で暗くし、後ろの画面（本棚など）が透けて見えるようにする。
- 見出しは明朝（`screen-title` を 20px 程度に小さくしたもの。迷ったら `book-title` の大きさを下げる）。中身の左右の余白は `space-6`。
- 後ろのタップ、下へのスワイプ、「閉じる」で閉じる。入力中のメモ・引用は、閉じても下書きとして残す。
- 開くときは下から 250ms ほどで減速しながら出る。「動きを減らす」がオンならフェードだけ。
- 読み上げではダイアログとして扱う。
