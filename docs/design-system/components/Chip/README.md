# Chip

選ぶための小さな丸い部品。

| 状態 | 面 | 枠 | 文字 |
| --- | --- | --- | --- |
| 選択中 | `accent` | `accent` | `accent-ink` |
| 未選択 | なし | `line` | `text-primary` |

- 高さ 36px（タップ領域は `hitSlop` で 44px 以上）、角丸 `radius-full`、左右の余白 14px、文字 `value`。
- **単一選択**（ステータス、一度に出す数）: 読み上げではラジオボタン。
- **複数選択**（本の登録画面の「本棚」）: 読み上げではチェックボックス。
- **切り替え**（本棚の画面の上部の本棚: 「すべての本」「SF」…）: 横にスクロールする1行。最後に点線の「＋ 本棚を作る」。
- ステータスの絞り込み（すべて／読んでる／読んだ／読みたい）はチップではなく、下線（`ribbon` 2px）のタブにする。各項目に件数を `label` で添える。
