# Chip

いくつかの中から1つを選ぶ部品。フォームの種別（5つ）とステータス（4つ）に使う。

| 状態 | 面 | 枠 | 文字 |
| --- | --- | --- | --- |
| 選択中 | `accent` | `accent` | `accent-ink` |
| 未選択 | なし | `line-strong` | `text-secondary` |

- 高さは `touch-min`（種別は5つを1行に収めるため 40px まで詰めてよい。その場合もタップ領域は `hitSlop` で 44px 以上にする）。角丸 10px。文字は `label`。
- 等幅のグリッドで並べる（種別は5列、ステータスは2列）。間隔 6px。
- 読み上げでは単一選択のグループ（ラジオボタン）として扱い、選択中を伝える。
- 選んだ瞬間に見た目を切り替える（待たせない）。
