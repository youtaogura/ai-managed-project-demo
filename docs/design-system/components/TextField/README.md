# TextField

1行の入力欄と、複数行の入力欄（感想）。

- 見出しは入力欄の上に `label`・`text-secondary`。必須の項目は見出しに「（必須）」、任意で目立たせたいものは「（任意）」と書く。
- 入力欄は面 `surface-2`、枠 `line`、角丸 12px、高さ `button-height`、左右の余白 14px。文字は `body`・`text-primary`、プレースホルダーは `text-tertiary`。
- フォーカス中は枠を `accent` にする。
- エラーは入力欄の下に `micro`・`danger` で出し、枠も `danger` にする。
- 複数行は高さ 120px から、内容に合わせて伸ばす。
- 日付の欄も同じ見た目のボタンにし、タップで日付の選択を開く。
- ISBN の入力欄だけは大きく（高さ 56px、文字 22px・太字）して、数字キーボードを出す。
