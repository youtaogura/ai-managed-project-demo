# Starter（書き出し）

読み終えたあとに、続きを書いてもらうための文の書き始め。「いちばん心に残ったのは、」のように、読点で終わる。

**続きを書く画面のカード**

- 選んでいるカード: 面 `surface-1`、枠 `ribbon` 1.5px、角丸 `radius-card`。書き出しを `starter`（ここでは `text-primary`）で上に、その下に続きを書く入力欄（`reading` の明朝、面 `bg`、枠 `text-primary`）。入力欄の下に「ページ」（任意）と「引用として残す」。
- 選んでいないカード: 面 `surface-1`、枠 `line`。書き出しと、右に「書く」。タップで選ぶ。
- 「ひとことで言うと、」はいつも一番上に、小さな欄で出す（`surface-2`）。

**読み返すときの組み方**

- 書き出しを `starter`（`ribbon`）で、続きの `reading` と**一続きの文章として**組む（改行しない）。例: 「**いちばん心に残ったのは、**嵐の夜、停電のなかで…」
- 書き出しが空のまま（続きを書かなかった）のものは出さない。

**書き出しの一覧（初期値）**

ひとことで言うと、（固定・いつも出す）／いちばん心に残ったのは、／読み終えて、見方が変わったのは、／この本を渡したいのは、／似ていると思ったのは、／作者がいちばん伝えたかったのは、たぶん／自分のことのように感じたのは、／少し引っかかったのは、

- ユーザーは書き出しを足す・オフにすることができる。読み終えたときに、オンのものからランダムに設定の数（2・3・5、初期値 3）を出す。
- 保存するときは、書いたときの書き出しの文も一緒に残す（あとで書き出しを編集しても、過去の記録の文章は変わらない）。
